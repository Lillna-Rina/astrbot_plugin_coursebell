# astrbot_plugin_course_reminder

AstrBot 课程提醒插件：**直接读取本地文件夹中的课表文件**，可查看 **今日 / 明日 / 本周 / 下周** 课表，支持 **课前提醒** 与 **每日定时推送课表**。

## 环境要求

- AstrBot >= 4.19.4
- 依赖：`icalendar`、`python-dateutil`、`tzdata`（从文件安装时由 AstrBot 自动安装）
- 可选：Playwright 渲染环境（课表以图片形式输出；未安装时自动降级为文本消息，功能不受影响）

## 安装

1. AstrBot 控制台 → AstrBot 插件 → 右下角 + → **从文件安装**，选择本插件 zip 包。
2. 在插件管理页打开插件的「配置」，设置 **本地课表文件夹路径（ics_dir）**：
   - 支持绝对路径（如 `D:/课表`）或相对 AstrBot 运行目录的路径；
   - **留空时**默认使用插件数据目录下的 `ics` 文件夹（`data/plugin_data/astrbot_plugin_course_reminder/ics/`）。
3. 把课表 `.ics` 文件放入该文件夹，启用/重载插件。

> 也可以不配置路径：直接把 `.ics` 文件放进默认的 `ics` 文件夹即可。

## 使用方式

插件**只读取本地文件夹中的 .ics 文件**，不需要（也不支持）上传文件。

### 绑定课表

- `/绑定课表`：列出文件夹中所有 `.ics` 文件，回复文件名完成绑定；
- `/绑定课表 文件名.ics`：直接绑定指定文件；
- **自动匹配**：如果文件名以你的用户 ID 开头（如 `123456.ics`、`123456_我的课表.ics`），插件会自动识别，无需手动绑定——发一次任意查询指令即自动生效。

### 指令一览

| 指令 | 说明 |
| --- | --- |
| `/课表文件` | 查看课表文件夹中的所有 .ics 文件 |
| `/绑定课表 [文件名]` | 选择/指定文件夹中的课表文件绑定 |
| `/删除课表` | 解除绑定（**不删除本地文件**） |
| `/示例课表` | 在文件夹中生成示例课表文件并绑定（含一节 20 分钟后开始的测试课，方便体验所有功能） |
| `/今日课表` `/明日课表` | 输出当日/明日课表 |
| `/本周课表` `/下周课表` | 输出本周/下周课表 |
| `/设置提醒时间` | 设置课前提醒的提前分钟数（1-120，默认 15） |
| `/设置每日推送` | 每日定时推送当日课表：回复「开启 HH:MM」或「关闭」 |
| `/查看设置` | 查看当前绑定文件与配置 |

其他：`/课表帮助` 查看指令列表；每个指令均支持简短别名（如 `/today`、`/week`）。

## 文件更新

- 插件每次读取前都会检测文件是否变化（修改时间/大小），**把新的 `.ics` 文件放入文件夹即自动生效**，无需重载插件；
- 同一个文件夹可放多个用户的课表文件，每个用户通过 `/绑定课表` 绑定自己的文件。

## 功能说明

### 课前提醒

- 插件每 60 秒扫描一次已绑定用户的课表；
- 课程开始前 `N` 分钟（默认 15，可配置）自动发送提醒，内容包含课程名、时间与地点；
- 同一节课只提醒一次，不会重复打扰。

### 每日定时推送

- 使用 `/设置每日推送` 开启后（格式 `开启 HH:MM`，24 小时制），每天指定时间自动推送当日课表；
- 定时任务持久化存储，插件重载/重启后自动恢复；
- 每天只推送一次。

## 数据存储

- 课表文件：你指定的本地文件夹（插件只读）；
- 绑定信息：`data/plugin_data/astrbot_plugin_course_reminder/bindings.json`（插件重装/更新不会丢失）。

## 常见问题

- **课表输出为文本而不是图片**：AstrBot 未安装 Playwright 渲染环境，功能不受影响；也可在 AstrBot 中安装 Playwright 后获得图片输出。
- **文件夹中没有文件**：确认 `.ics` 文件已放入配置的文件夹（可在 WebUI 插件配置中查看路径），并已发送 `/绑定课表`。
- **时区**：插件固定按东八区（Asia/Shanghai）计算日期与提醒时间。
